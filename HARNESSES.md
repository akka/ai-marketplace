# Installing the `akka` plugin across AI harnesses

The `akka` plugin ships to multiple AI coding harnesses from a single source of
truth — `plugins/akka/commands/*.md`. Each harness's native artifacts are
generated by `bin/generate-harnesses.py` and committed so the harness installers
resolve this one repository. The `akka mcp serve` MCP server is registered in
every harness, so the full Akka toolset is available regardless of command format.

## Install

| Harness | Command |
|---|---|
| **Claude Code** | `/plugin marketplace add akka/ai-marketplace` then `/plugin install akka@akka` |
| **Gemini CLI** | `gemini extensions install https://github.com/akka/ai-marketplace` |
| **Codex CLI** | `codex plugin marketplace add akka/ai-marketplace` then `codex plugin add akka@akka` |
| **Cursor / VS Code Copilot** | `akka specify init --agent cursor` / `--agent vscode-copilot` |

## Invocation differs by harness

The **MCP toolset (`akka mcp serve`) is identical in every harness** — same `akka_*`
tools. The slash-command invocation, however, depends on what each harness supports:

| Harness | How commands are invoked |
|---|---|
| Claude Code | `/akka:specify` (plugin slash commands) |
| Gemini CLI | `/akka:specify` (colon-namespaced custom commands) |
| Codex CLI | as **skills** — `@akka` / model-selected / natural language (no `/akka:` slash) |
| Cursor | rules + MCP / `@`-mentions (no `/akka:` slash) |

So `/akka:specify` parity holds for Claude Code and Gemini; Codex and Cursor reach
the same prompts and tools through their native mechanism.

## How it maps

| Harness | Manifest (committed) | Commands become | MCP |
|---|---|---|---|
| Claude Code | `.claude-plugin/marketplace.json` + `plugins/akka/` | `commands/*.md` (source) | project `.mcp.json` (via `akka specify init`) |
| Gemini CLI | `gemini-extension.json` | `commands/akka/*.toml` | `mcpServers` in the manifest |
| Codex CLI | `.agents/plugins/marketplace.json` + `.codex-plugin/plugin.json` | `skills/akka-*/SKILL.md` | `.mcp.json` (`servers`) |

Claude-specific `handoffs` frontmatter is dropped for the other harnesses;
`$ARGUMENTS` becomes `{{args}}` for Gemini.

## Regenerating

After editing any `plugins/akka/commands/*.md`, regenerate the harness artifacts:

```
python3 bin/generate-harnesses.py
```

CI should run this and fail on drift so the committed harness artifacts stay in
sync with the source commands.
